# 通用工具

不需要 AI，纯手动使用。

---

## 这是什么

`pobridge.min.js` 是一段 4.3KB 的 JS，注入到 ProcessOn 页面后提供：

```js
POBridge.readGraph()              // 读取整张图的结构
POBridge.createNode({...})        // 创建节点（默认红色）
POBridge.updateNode(id, {...})    // 修改节点
POBridge.removeNodes([id])        // 删除节点
POBridge.createEdge({...})        // 创建连线
POBridge.getViewBox()             // 获取当前视口范围
```

---

## 装书签（三分钟）

1. 双击 `书签安装页.html`，用浏览器打开
2. 按 `Ctrl+Shift+B` 显示书签栏
3. 把页面上的蓝色按钮**拖到书签栏**
4. 去 ProcessOn 画布页，点一下这个书签
5. 右上角出现绿色提示 = 成功

---

## 用法示例

注入后按 F12 打开控制台，可以这样用：

```js
// 看这张图有什么
var g = POBridge.readGraph();
console.table(g.nodes.map(n => ({id: n.id.slice(0,8), name: n.name, text: n.text})));

// 加一个红色节点（坐标省略会自动放在当前视口）
POBridge.createNode({ text: '我加的一步', w: 220, h: 90 });

// 改文字
POBridge.updateNode('某个id', { text: '新文字' });

// 删除
POBridge.removeNodes(['某个id']);
```

## 已知的坑

| 坑 | 现象 | 解法 |
|---|---|---|
| 直接用 Model.addMulti | 数据变了画布不动 | 用 POBridge 封装好的方法 |
| 坐标在视口外 | **静默删除，不报错** | 用 createNode 时省略坐标 |
| 颜色写 #ff0000 | 不生效 | 用 RGB 逗号串 '255,0,0' |
| 字段不全 | 渲染器跳过 | 用 createNode 自动补全 |

这些坑 POBridge 都已经处理好了，正常调用不会踩到。
