# ProcessOn 流程图 AI 助手

> ⚠️ **非官方项目，与 ProcessOn 官方无关联。** 完整声明见仓库根目录 `DISCLAIMER.md`。

让 AI 在**你已经打开的 ProcessOn 画布上**做增量修改 —— 加一步、改文案、连箭头，
改动用红色高亮，改完自动保存。

两套实现，原理不同，按你用的 AI 工具选一套；也可以两套都装。

---

## 三十秒选择

| 你的情况 | 用哪套 |
|---|---|
| 要在现有图上精确改（加一个环节、改文案） | **两套都能做**，挑你顺手的 |
| 用 DeepSeek Harness | `01-DSH方案` |
| 用 WorkBuddy | `02-WorkBuddy方案` |
| 不想装任何扩展、也不想装技能，想自己试试 | `03-通用工具`（手动点书签） |
| 从零生成一整张新图 | 都不行，走 ProcessOn 自带 AI 或官方 MCP |

---

## 三套方案的实际差异

| | 01 DSH | 02 WorkBuddy | 03 通用工具 |
|---|---|---|---|
| 原理 | 浏览器扩展 + 运行时注入 | Playwright 自带 Chromium + 运行时注入 | 书签按钮，人工点一下 |
| 要装扩展 | ✅ 必须 | ❌ 不用 | ❌ 不用 |
| 要装技能 | ✅ | ✅（可选） | ❌ |
| 谁执行 | AI（扩展） | AI（命令行） | **人** |
| 占用你的浏览器 | 是 | 否 | 否 |
| 需要登录态 | 复用你的 | 不用（靠 URL 票据） | 复用你的 |
| 改动实时出现在你眼前 | 是 | 协同同步（必要时刷新） | 是 |
| 能否无人值守 | 否 | ✅ | 否 |
| 增量精确改图 | ✅ | ✅ | ✅ |

> 两套自动化方案共用同一份注入层（`pobridge.min.js`），改图能力完全一致，
> 差别只在「AI 怎么碰到页面」。

## 一个必须说清楚的依赖问题

**AI 要操作你的浏览器，就必须有"手"。**

- 技能（`SKILL.md`）只是一份说明书，它自己执行不了任何东西。
- 01 方案的手 = DSH 浏览器扩展（第三方组件，从插件市场装，**不在本包里**）；
- 02 方案的手 = Playwright 起的独立 Chromium（它自带手，不需要你的浏览器）；
- 03 方案的手 = 你自己点一下书签。

`03-通用工具` 的书签解决的是「**人**在页面上执行代码」，不是「**AI**在页面上执行代码」。
这两件事不一样，别混。

## 安全须知

1. **AI 不会自动保存**（01 方案）。改动只在内存里，保存必须你自己按 Ctrl+S。
   02 方案默认会自动 Ctrl+S。
2. **改动会实时同步给同事**。动手前在群里说一声。
3. **这是非官方接口**。ProcessOn 没承诺这些内部对象稳定，发版可能失效。
4. **别拿它改重要且没有备份的图**。先在副本上试。
